## data_center_projects_synthetic.csv (810 rows, 12 columns)
| Column | Type | Meaning |
|---|---|---|
| Project_ID | text | Unique project id (DC0001...) |
| Company | text | Investing company (fictional) - joins to companies_fictional.csv |
| Announcement_Date | date | YYYY-MM-DD (2019-01-01 to 2026-10-29) |
| Year | int | Year of announcement |
| Country, Region, City | text | Location |
| Infrastructure_Type | text | Hyperscale, Colocation, Enterprise, Edge, AI Training Campus, AI Inference Cluster |
| AI_Focused | text | Yes / No |
| Capacity_MW | float | Planned IT capacity in megawatts |
| Investment_USD | float | Project investment in USD |
| Project_Status | text | Announced, Under Construction, Operational, Cancelled |

### Built-in patterns (assumptions used to generate the data)
- Number of projects, capacity and spending grow over time; AI share rises from ~4% (2019) to ~66% (2026).
- 2026 is a partial year (to 29 Oct 2026) - do not compare it with full years without noting this.
- Investment = capacity x cost per MW x location multiplier x inflation. Cost per MW is an ASSUMPTION
  (higher for AI types than traditional). These are not sourced industry figures.
- US, China, India and Europe have the most projects; locations are weighted by hand, not by real data.

### Deliberate data-quality issues (for the cleaning step)
- 10 duplicate rows (same Project_ID appears twice)
- 12 missing Investment_USD, 8 missing City
- 15 rows with Country = "USA" instead of "United States"
- 6 rows with AI_Focused = "yes" (lowercase) instead of "Yes"
